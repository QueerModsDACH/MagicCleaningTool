# Magic Cleaning Tool – Installation

Das Magic Cleaning Tool ist ein Userscript für Twitch. Zur Installation benötigst du einen Userscript-Manager und einen unterstützten Browser.

## Voraussetzungen

Installiere zunächst einen passenden Userscript-Manager für deinen Browser:

| Browser | Userscript-Manager |
|---|---|
| Chrome | [Tampermonkey](https://chrome.google.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox | [Greasemonkey](https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/), [Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/) oder [Violentmonkey](https://addons.mozilla.org/firefox/addon/violentmonkey/) |
| Edge | [Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd) oder [Violentmonkey](https://microsoftedge.microsoft.com/addons/detail/eeagobfjdenkkddmbclomhiblgggliao) |
| Safari | [Tampermonkey](https://apps.apple.com/us/app/tampermonkey/id1482490089) |
| Opera | [Tampermonkey Beta](https://addons.opera.com/en/extensions/details/tampermonkey-beta/) |

Die Verfügbarkeit und Bedienung von Erweiterungen kann je nach Browser und Betriebssystem abweichen.

## Installation des Userscripts

1. Installiere den Userscript-Manager und aktiviere ihn im Browser.
2. Öffne anschließend den Installationslink des Magic Cleaning Tools:

   [Magic Cleaning Tool installieren](https://github.com/QueerModsDACH/MagicCleaningTool/raw/refs/heads/main/MagicCleaningTool.user.js)

3. Dein Userscript-Manager sollte eine Installationsseite für das Script öffnen.
4. Prüfe den angezeigten Namen des Scripts und bestätige die Installation.
5. Öffne Twitch neu oder lade die Twitch-Seite erneut.
6. Melde dich bei Twitch an und öffne den Moderatorenbereich eines Kanals, den du moderieren darfst.

## Tool öffnen

Wenn Twitch einen Moderationskontext erkennt, erscheint ein Aktivierungssymbol in der Nähe der Moderationswerkzeuge. Klicke darauf, um das Magic Cleaning Tool zu öffnen.

Das Tool kann nur in einem passenden Moderationskontext verwendet werden. Wenn das Aktivierungssymbol nicht erscheint, prüfe, ob du angemeldet bist und tatsächlich Zugriff auf den Moderatorenbereich des Kanals hast.

## Updates

Userscript-Manager können installierte Scripts aktualisieren. Wenn eine neue Version verfügbar ist, sie aber nicht automatisch installiert wird, öffne die Script-Verwaltung deines Managers und suche dort nach einer Funktion wie „Nach Updates suchen“ oder „Update prüfen“.

Bei Tampermonkey kann die interne Update-Prüfung erforderlich sein, wenn eine neuere Version auf der Projektseite angezeigt wird, Tampermonkey aber noch kein Update meldet.
